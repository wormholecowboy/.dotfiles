Live Context UI — a page that keeps up with the conversation.

Your instinct is right: separate the data from the view. Claude appends tiny events, cv folds them into state, and a local page renders it with prebuilt components. Four refinements make it cheap per update, durable across compaction, and two-way.

03The four refinements

What changes from "JSON file + inject via CLI".

1 · storage

Append-only event log

Every update is one line appended by a tiny CLI. No read-before-write, cost stays flat as the session grows, and you get a timeline for free.

2 · capture

Hooks log the mechanical stuff

PostToolUse records files touched, commands run, tests pass/fail — zero model tokens. Claude only writes judgment: plan, decisions, questions, diagrams.

3 · direction — biggest win

Make it two-way

Check off, answer, annotate in the UI; it appends to the same log. UserPromptSubmit injects your changes since the last turn. No more answering Q3/5 in the terminal.

4 · memory

It's Claude's working memory too

After compaction, a SessionStart hook prints cv dump, so compact structured state comes back automatically instead of a lossy summary. At session end, distill into .mem/.

08Pitfalls

Where this kind of tool usually goes stale or sprawls.

Claude forgets to update

The page quietly drifts from reality.

FixShort skill / CLAUDE.md rule, plus a Stop hook that blocks when edits were logged this turn but no Claude events were.

Wrong state scope

Session-ID keys vanish on /clear or restart.

FixKey the log by repo + branch.

Schema creep

Every new need becomes a new component type.

FixFixed, small component set. Every item gets an id.

file:// can't fetch or watch

A bare HTML file can't load the log or receive pushes.

FixTiny local server; lsof the port before starting.

09Alternative: hosted Artifact + database

The same shape already exists on claude.ai — useful for testing the UX before building.

Local build · recommended

Hackable, wired into hooks

  • Data stays on disk next to the repo
  • Hooks write directly; no API in the loop
  • Any component you want, any time
Hosted artifact

Exists today, zero setup

  • Page + shared DB; Claude writes rows without republishing
  • Private by default, shareable link
  • Lives on claude.ai; harder to customize; no hook integration
